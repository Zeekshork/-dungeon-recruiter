# Demon Summoner: Knight Siege

A tiny browser mini-game where you summon demons (imps and brutes) to defend your altar against incoming knight waves.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser.

## How to play

- Gain souls passively over time.
- Spend souls to summon demons.
- Start each wave when you're ready.
- Defeat knights to earn bonus souls.
- If knights reach your altar and reduce HP to 0, you lose.
